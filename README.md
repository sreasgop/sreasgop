### 💫 About Me

> *"Writing code that impacts lives & demystifying lower levels of abstraction."*

- 🎓 **Educator & Entrepreneur:** Currently working as a Computer Science Educator and CEO at **Sprint Tech Academy**, empowering the next generation of tech innovators and spreading technological literacy.
- 🚀 **Coding Journey:** Started my programming journey back in **2015** with **Liberty BASIC**, followed by **HTML & Python** in grade 5.
- ⚙️ **Core Passion:** Deeply interested in low-level systems programming, abstraction layers, software architecture, and developer productivity tools.
- 🌐 **Mission:** Crafting scalable software solutions and bridging the gap between high-level applications and low-level compute dynamics.
